# Security policy

adhd-status is plain text (Markdown, YAML, JSON and images) with no code, dependencies or network
calls. See [PRIVACY.md](PRIVACY.md).

## Reporting a vulnerability

If you find a problem, for example an instruction in the skill that could make an agent leak data
or run something unsafe, please report it privately through GitHub's
[private vulnerability reporting](https://github.com/maumoya/adhd-status/security/advisories/new).
You will get an answer within 7 days.

## Supported versions

Only the latest version on `main` is supported.
